# 💳 Desafío Final - Proyecto GiftCard

## 📚 Curso: **Java: trabajar con listas y colecciones de datos** – *Oracle Next Education (ONE) – Alura Latam*

## 🧾 Descripción:
Este proyecto simula una tarjeta de crédito que permite realizar compras, controlar el saldo disponible y visualizar un resumen de los gastos realizados, utilizando listas y ordenamientos.

A través de este ejercicio reforcé conceptos fundamentales del manejo de colecciones en Java, la implementación de clases personalizadas y la lógica de interacción con el usuario a través de consola.

> *(Como toque personal, adapté la tarjeta para que funcione como una GiftCard que permite comprar un máximo de 3 productos.)*

## 🛠️ Habilidades adquiridas:
- Uso de **listas dinámicas** con `ArrayList`.
- Implementación de la interfaz `Comparable` para ordenar objetos personalizados.
- Aplicación de **estructuras condicionales** y bucles `while`.
- Control de flujo de un programa orientado a consola.
- Práctica en **encapsulamiento y organización de clases**.
- Desarrollo de una lógica orientada a la experiencia del usuario.

## 💻 Tecnologías utilizadas:
- Lenguaje: Java 24  
- Entorno: IntelliJ IDEA  
- Entrada de datos: `Scanner`  
- Ordenamiento: `Collections.sort()`  
- Programación orientada a objetos  

## 🧠 Conclusión:
Este proyecto me permitió aplicar de manera práctica los conocimientos adquiridos sobre colecciones y lógica de control en Java. Comprendí mejor cómo modelar el comportamiento de objetos dentro de un programa realista, manteniendo el código limpio, funcional y orientado al usuario.
